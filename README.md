# Hotech Globe Tracker — Codex Starter Pack

This folder is the canonical project handoff for a simple Globe Fiber application tracker.

## Read order for Codex

1. `docs/PROJECT_MEMORY.md`
2. `docs/NEXT_TASK.md`
3. Only open another document when the active task requires it.

Do not load every document on every turn. This keeps context and token use small.

## Canonical documents

- `docs/PROJECT_MEMORY.md` — compact persistent truth
- `docs/HANDOFF.md` — stack, scope, workflow, and acceptance rules
- `docs/PRODUCT_REQUIREMENTS.md` — roles, fields, statuses, and permissions
- `docs/UI_DASHBOARD_CONTRACT.md` — frozen dashboard visual direction
- `docs/IMPLEMENTATION_PLAN.md` — phased build plan
- `docs/DECISIONS.md` — approved decisions and change log
- `docs/NEXT_TASK.md` — only the next bounded task
- `docs/CODEX_WORKING_RULES.md` — implementation and token-efficiency rules
