| D-041 | 2026-09-16 | Owner accepted MVP-2A's Plans concurrency approach as a durable decision: Plans use the exact current `updated_at` value as their optimistic concurrency token (`expected_updated_at`), since the frozen Phase 02 Plans schema has no `version` column.
